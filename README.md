# The Winchester Files

An interactive _Supernatural_-inspired fan archive dedicated to Dean and Sam Winchester, their legendary 1967 Chevrolet Impala, memorable cases, and Dean’s classic-rock collection.

Built with React, TypeScript, and Vite, the website combines editorial design, hunter-journal aesthetics, humor, animations, and interactive storytelling.

## Features

- Responsive editorial layout
- Interactive Dean and Sam character profiles
- Animated highway and Winchester road story
- Dedicated section for the 1967 Chevrolet Impala
- Paginated journal-style case files
- Interactive cassette player and rock playlist
- Random case generator with 20 possible hunts
- Scroll-reveal and hover animations
- Mobile-friendly navigation
- Reduced-motion accessibility support

## Built With

- React
- TypeScript
- Vite
- CSS
- HTML

## Getting Started

### Requirements

Install [Node.js](https://nodejs.org/) version 20 or newer.

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/winchester-brothers-archive.git
```

Open the project folder:

```bash
cd winchester-brothers-archive
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address displayed in the terminal.

## Production Build

Create an optimized production build:

```bash
npm run build
```

The deployable files will be generated inside the `dist` folder.

To preview the production build locally:

```bash
npm run preview
```

## Deployment

This is a standard static Vite project and can be deployed through:

- Vercel
- Netlify
- Cloudflare Pages
- GitHub Pages

The project uses credited editorial images hosted by external sources, so an internet connection is required for the images to load.

## Project Inspiration

The design is inspired by John Winchester’s journal, vintage case files, American highway maps, cassette tapes, classic-rock culture, and the Winchester brothers’ life on the road.

> “Saving people. Hunting things. The family business.”
