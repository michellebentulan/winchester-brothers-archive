# The Winchester Files

A standalone React + TypeScript + Vite edition of the interactive Supernatural fan archive.

## Run locally

1. Install Node.js 20 or newer.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown in the terminal.

## Production build

Run `npm run build`. The deployable files will be generated inside `dist/`.

## Deploy

This is a standard static Vite project and can be deployed to Vercel, Netlify, Cloudflare Pages, or GitHub Pages. The project currently loads credited editorial images from their source URLs, so an internet connection is required for those images.

## Included interactions

- Responsive navigation and scroll reveals
- Interactive Dean and Sam profiles
- Highway story notes
- Paginated journal-style case files
- Interactive cassette and track selection
- Twenty-option case generator
